Импорт измерений TXT / JSON

Данные импортируются только по вашему выбору, не считываются с WebSDR автоматически.
Формат файлов

JSON: массив записей или объект с полем measurements. Каждая запись: mhz (МГц), mode, strength, time (ISO 8601), source.

TXT: одна запись в строке, поля разделены точкой с запятой: частота МГц; тип; уровень; время ISO 8601; источник. Первая строка может содержать заголовки mhz;mode;strength;time;source. Пример: 145.500;FM / NFM;-81.4 dBm;2026-10-09T10:00:00Z;Мой приёмник.

Импортированные записи обозначаются отдельно от ручных. Источник файла указывается как предоставленный пользователем, а не проверенный приложением.

Исторические аномалии спектра

Отдельный анализатор архивных измерений мощности (dBm). Не сканирует эфир и не определяет тип источника. Используйте обезличенные данные с задержкой не меньше 24 часов. Результаты относятся только к указанному в файле измерительному источнику, не к выбранному квадрату карты.
Архив не загружен.
Формат исторического файла

TXT: time;frequency_mhz;power_dbm;source. Например: 2025-01-01T00:00:00Z;100;-100;lab-test. Первая строка может быть заголовком. JSON: массив объектов с полями time, frequency_mhz, power_dbm, source или объект {measurements: [...]}. Для анализа требуется минимум 9 последовательных измерений на одной частоте от одного источника. Сохранение на сервер не выполняется.

Результатов пока нет.

Лабораторная проверка алгоритма · 3.3

Проверка лабораторного CSV с документированными метками присутствия сигнала. Файл анализируется локально; используется мощность Power и эталонная метка Signal presence (any). Тест не определяет рации, географические координаты или текущую активность радиоэфира.
📋 Паспорт лабораторного набора

Заполняется по документации источника; неизвестное оставьте пустым. Метки двух передатчиков не являются метками «шум/сигнал».

Выберите исходный dataset.csv, затем нажмите «Проверить обнаружение».
Дополнительная проверка 3.3: пять воспроизводимых разбиений 80/20. Она оценивает разброс результатов внутри того же CSV, но не заменяет независимый эксперимент.
Как проводится проверка

При отсутствии пригодного поля сеанса — детерминированное разбиение строк: каждая пятая строка — тестовая (20%), остальные — обучающая часть (80%). Порог строится только по обучающим записям с эталонной меткой «нет сигнала»: медиана мощности + максимум из 3 dB и 6 × нормализованного MAD. На тесте метки используются исключительно для оценки качества. При упорядоченных/зависимых данных эта оценка может быть оптимистичной; результат не является доказательством способности находить произвольные рации.

Лабораторных результатов пока нет.

Автоматическое обнаружение

Для автоматического отображения радиопередач необходим согласованный машинный интерфейс измерений (частота, уровень, время). У публичной страницы этого приёмника такой интерфейс пока не подтверждён. Приложение не пытается обращаться к внутренним или закрытым интерфейсам сервера.
